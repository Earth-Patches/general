# 🌍 Earth-Patches/general

> *The world is a repository. Somebody has to maintain it.*

Welcome to **general**, the main repository of **Earth-Patches**: a satirical project that treats the world as one very large, very old, poorly documented codebase.

No one knows who the original author was. The commit history begins with a single commit titled `Initial commit` (13.8 billion years ago) and has been force-pushed to ever since.

**Disclaimer:** This is satire. These patches are not real, will not change the world, and should not be applied to anything, least of all reality.

## What happens in this repository

- **Bug reports**: Things are broken. We file issues about them.
- **Patches**: Small, well-intentioned fixes for the world's more persistent bugs, written with the confidence of someone who has not read the rest of the code.
- **Code review**: Every change is reviewed by at least one person who says "LGTM" without opening the diff.
- **Technical debt**: Considerable. See `TODO.md` (last updated: the Bronze Age).
- **Dependencies**: Eight billion contributors, no lockfile.

## Getting patches

New patches are published through **[Releases](../../releases)**. We do not merge to `main` and hope for the best (well, not officially).

Each release includes:

- A version number and a release title with unjustified optimism
- A changelog of what was fixed, and what was broken in the process
- Assets you are free to download and not apply

To get the latest patch:

1. Open the [Releases page](../../releases).
2. Select the release marked **Latest**.
3. Read the release notes. Yes, all of them.
4. Download the assets.
5. Consider whether applying them to the world is wise. (It is not.)

> **Tip:** Click **Watch → Custom → Releases** to be notified when a new patch drops. It's the closest thing to a weather forecast for civilization.

## Versioning

We follow [Semantic Versioning](https://semver.org/), loosely, the way the world follows most rules.

| Part | Meaning |
| ---- | ------- |
| `MAJOR` | Breaking changes (ice ages, empires, new smartphone chargers) |
| `MINOR` | New features that mostly stay backward compatible |
| `PATCH` | Small fixes, such as finally labeling the "push" and "pull" sides of doors |

## Reporting problems

If a patch makes things worse (it will), please [open an issue](../../issues) and include:

- The release version you applied
- What you expected to happen
- What actually happened
- Whether the problem appeared before or after the patch (we will assume after)
